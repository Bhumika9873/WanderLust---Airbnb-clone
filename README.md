# WanderStay

A modern full-stack vacation rental platform where users can explore stays, create listings, book properties, save favorites, write reviews, and manage their travel experience.

## Live Demo

https://wanderstay-8u9z.onrender.com

## Features

- User Authentication (Signup/Login/Logout)
- Create, Edit and Delete Listings
- Property Booking System
- Wishlist
- Reviews
- Search Listings
- Secure Image Uploads with Cloudinary
- Responsive UI
- Flash Messages
- Session-based Authentication

## Tech Stack

## Installation

```bash
git clone https://github.com/Bhumika9873/WanderStay.git
```

```bash
cd WanderStay
```

```bash
npm install
```

Create a `.env` file

```env
ATLASDB_URL=
SECRET=
MAP_TOKEN=
CLOUD_NAME=
CLOUD_API_KEY=
CLOUD_API_SECRET=
```

Run the application

```bash
node app.js
```

Open

```
http://localhost:8080
```
